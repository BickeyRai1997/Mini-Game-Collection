# 🎮 Mini Game Collection

A collection of classic browser games built with vanilla HTML, CSS, and JavaScript.

## 🕹️ Games Included

| Game | Description |
|------|-------------|
| 🐍 **Snake** | Classic snake game with score tracking and high score saved in localStorage |
| ❌ **Tic-Tac-Toe** | Two-player tic-tac-toe with win detection and score tracking |
| 🧠 **Memory** | Match pairs of emojis in this memory card game |

## 🚀 Features

- 🎯 Three games in one page
- 📱 Fully responsive design
- 🏆 High score saved locally (Snake)
- ⌨️ Keyboard controls (Snake)
- 🎨 Smooth animations and modern UI
